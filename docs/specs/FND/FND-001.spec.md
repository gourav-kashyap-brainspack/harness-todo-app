# FND-001 — Stack install & feature-sliced scaffolding

## Goal
Turn the bare RN 0.75.5 scaffold (`react` + `react-native` only) into the project's real foundation: install & wire the full harness stack, create the feature-sliced `src/` tree with the `@/*` path alias, and turn on `eslint-plugin-boundaries` so the layering is enforced from task #1. This is the anchor task every other FND/PRO/TSK/ORG task builds on — nothing else can start until the stack compiles, lints clean, and the app boots.

## Functional requirements
- **FR1 — Install the base stack** (current-stable resolved at build via `npm view <pkg> version`; **RN-coupled packages pinned to RN 0.75**, per the Dependency Version Policy). Install with `npm install <pkg> --legacy-peer-deps`:
  - Styling: `nativewind@^4` + `tailwindcss@3.4.x` (dev)
  - Navigation: `@react-navigation/native@6`, `@react-navigation/native-stack@6`, `@react-navigation/bottom-tabs@6`, plus peers `react-native-screens`, `react-native-safe-area-context`
  - State: `zustand@5`
  - Forms/validation: `react-hook-form@7`, `zod@3`, `@hookform/resolvers`
  - Storage: `react-native-mmkv` (installed here so FND-004's first-launch flag can read it; the typed storage **service** is STG's job)
  - Icons: `react-native-vector-icons` (+ `@types/react-native-vector-icons` dev) with the Android `fonts.gradle` + iOS `Info.plist` font wiring
  - Native splash: `react-native-bootsplash` (config in FND-004)
  - Lint boundaries: `eslint-plugin-boundaries` (dev)
  - Dormant (installed, NOT wired to any server per OQ-1): `axios`, `@tanstack/react-query`, `jwt-decode`, `date-fns`, `react-native-keychain` — **carried for a future cloud-sync phase; must not gate the offline build and must not be imported by feature code in this MVP.**
- **FR2 — Configure NativeWind 4:** `tailwind.config.js` (content globs → `./src/**/*.{ts,tsx}`, `./App.tsx`), `global.css` with the Tailwind directives, `babel.config.js` preset (`nativewind/babel`), `metro.config.js` wrapped with `withNativeWind`, `nativewind-env.d.ts` types, and `app.d.ts`/`className` typing. Verify a `<View className="flex-1 bg-white">` renders.
- **FR3 — Feature-sliced folder tree** under `mobile/src/` exactly per `conventions.md`: `app/` (navigation + providers), `core/{api,config,hooks,lib,services,store,types}`, `features/`, `components/ui`, `platform/`, `theme/`. Seed each with an `index.ts` barrel or a `.gitkeep` so the tree is real.
- **FR4 — Path alias `@/* → src/*`** in `tsconfig.json` (extend the RN base config, add `baseUrl`+`paths`) AND `babel.config.js` (`babel-plugin-module-resolver`), so `import { x } from '@/core/...'` resolves at type-check, bundle, and test time.
- **FR5 — `eslint-plugin-boundaries` config** (legacy `.eslintrc.js`, `ESLINT_USE_FLAT_CONFIG=false`): define element types `app`/`features`/`core`/`components`/`theme`/`platform` by path, and rules enforcing the layer direction `app → features → core|components|theme` with **no cross-feature imports**. A violation must be an **error** (gate runs `--max-warnings=0`).
- **FR6 — Providers composition-root skeleton** in `src/app/` (e.g. `AppProviders.tsx`) wrapping children with `SafeAreaProvider` + `GestureHandlerRootView` (nav peers) and a placeholder for the theme provider (FND-002) and navigation (FND-003). `App.tsx` renders `<AppProviders>` and the default RN sample screen is deleted.
- **FR7 — Jest still green:** update `jest.config.js` (preset `react-native`) with the NativeWind/module-resolver transform + `transformIgnorePatterns` for the new ESM deps; keep the existing smoke test (or replace with a trivial render test of `App`).

## Non-functional requirements
- **Performance:** no measurable cold-start regression from wiring alone; dormant deps must not be imported on the boot path (tree-shaken/unused).
- **Maintainability:** every install pins an exact/caret version in `package.json`; `package-lock.json` committed; resolved versions + date recorded in `docs/context/stack.md` (librarian, on done).
- **Security:** `npm audit` shows no new High/Critical from the added deps (SCA gate).

## UI / design notes
- No user-facing screens. Deletes the RN sample `App.tsx` content; the app boots to a minimal placeholder inside `AppProviders` until FND-003/004 land.
- Establishes the NativeWind `className` styling pattern (Tier-1) that every later component uses — **no `StyleSheet.create` for new components** unless NativeWind can't express it.

## Platform divergence (iOS / Android)
- **Icons:** Android needs `apply from: "../../node_modules/react-native-vector-icons/fonts.gradle"` in `android/app/build.gradle`; iOS needs the font files added to `Info.plist` `UIAppFonts` (and `pod install`). 
- **CocoaPods:** run `cd ios && pod install` after native-dep installs (macOS). Note Android autolinking picks up native modules on next build.
- Otherwise no behavioral divergence in this task.

## Offline / degraded network
- The app must build and boot with **no network dependency whatsoever** (F-048 groundwork). No provider or boot step may require connectivity. `react-query` is not mounted.
